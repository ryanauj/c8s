📊 Kubernetes Resource Visualizer

A full-stack application that provides an interactive graph visualization of your Kubernetes cluster resources. When connected to a real cluster, you'll see:

🖥️ Cluster Nodes

Physical or virtual machines in your cluster displayed as blue nodes

📦 Pods

Running containers grouped by namespace shown in green

🚀 Deployments

Deployment resources managing your pods in orange

🌐 Services

Service endpoints exposing your applications in purple

✨ Key Features

  • Context Switching: Easily switch between different Kubernetes contexts using the dropdown
  • Interactive Graph: Pan, zoom, and drag nodes to explore your cluster topology
  • Relationship Mapping: Visual edges show connections between pods, nodes, deployments, and services
  • Real-time Status: See the current status of each resource (Running, Pending, Failed)
  • Namespace Grouping: Pods are organized by namespace for better clarity
  • Minimap Navigation: Quick overview and navigation with the minimap control

🚀 Getting Started

To use this application with your Kubernetes cluster:

  1. Ensure you have kubectl configured with access to your cluster
  2. Start the backend: cd backend && npm run dev
  3. Start the frontend: cd frontend && npm start
  4. Open http://localhost:3000 in your browser
  5. Select your Kubernetes context from the dropdown
  6. Watch your cluster resources visualize in an interactive graph!

🔧 Technical Stack

Backend:
  • Node.js + Express
  • TypeScript
  • @kubernetes/client-node
Frontend:
  • React + TypeScript
  • react-flow
  • Axios

Note: This demo page shows the UI structure. When connected to a real Kubernetes cluster, the main area would display an interactive graph visualization using react-flow with your actual cluster resources.
